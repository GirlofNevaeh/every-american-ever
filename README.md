# Every American Ever

A guide to the 50 states, Native nations, and every president, for ages 5 to 12.

## Deploy on Vercel

1. Import this repo.
2. Leave the framework as **Other**. Do not set an output directory.
3. Use Node.js **22**.
4. Install command: `npm install --omit=dev --no-audit --no-fund`
5. Build command: `npm run build`

The build writes Vercel's Build Output (`.vercel/output`). No database is required.
